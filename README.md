# fourty_five

45° — Creative Technology Company website.

Creative direction and technology, shaped around real business problems.

## Architecture

- **Stack**: React + Vite + Vanilla CSS
- **Typography**: Syne (Display) + Inter (Body/Mono)
- **Palette**: Warm Ivory (`#F3F0E8`), Pale Blue (`#DCE6F5`), Soft Violet (`#DCD5F0`), Cobalt Blue (`#4269B2`), Warm Gold (`#D5A85C`), Deep Ink (`#202633`)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
